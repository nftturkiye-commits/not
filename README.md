# Süslü Kenarlı, Resimli Not Defteri

Bu proje, **A5 boyutunda (148 mm × 210 mm)**, süslü kenar ve ara ara resim içeren bir not defteri şablonu üretmeyi amaçlar.  
Şablon, **PDF/X‑1a** (CMYK, 300 dpi, 3 mm bleed) formatında çıktı alınabilir ve InDesign, Word ya da LaTeX kaynak dosyalarıyla sürüm kontrolü yapılabilir.
